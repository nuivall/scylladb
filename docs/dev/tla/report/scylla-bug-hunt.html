ScyllaDB Correctness Hunt

Twenty-five correctness bugs in ScyllaDB found by modelling (TLA+, then Veil) and by targeted code reading, with a cluster reproducer, a candidate fix, and a severity rating for each. Severity weighs the damage (silent data loss or resurrection ranks highest) against how likely the trigger is in production. Nothing here has been filed: every Jira ticket is a draft in docs/dev/tla/drafts/.

Severity scale

Critical

Silent data loss or resurrection reachable in a default configuration through ordinary operations (scale-out, repair, rebuild, RF change, restore, truncate). No error tells the operator.

High

Silent loss, resurrection or a security hole that needs a rarer trigger: a crash at the wrong moment, a failure mid-operation, a non-default but allowed topology.

Medium

Loud failures (crash, stuck node), inconsistencies that heal on restart, or experimental features.

Low

Wrong but harmless or self-correcting state, or an anomaly whose damaging effect is fenced on a real cluster.

How to read the reproducer and fix columns

"Fails 5/5" means the cluster test failed on all five runs on the bench (dev build) with the bug present, and its control variant passed. "Passes 3/3" in the fix column means the same test passed three times with the TEST-ONLY candidate fix applied; related existing test suites were run once with the fixes in (213, 107 and 134 tests passed; the one failure, test_counter_ids_reuse_in_single_rack, pins the design the #11/#17 fix replaces and is marked xfail). After a code review, the #1, #11/#17, #23 and #25 fixes were revised and re-run locally: the affected reproducers passed 3/3 and the regression tests passed. The reproducers of #2, #6 and #7, whose fixes are upstream, are marked xfail. Final sweep: without fixes, every reproducer failed 5/5 (149 failures) and every control passed (96); with all fixes, every reproducer passed 3/3 (138) except #2, #6 and #7, whose fixes are upstream PRs. Candidate fixes are proofs of concept on the experiment branch, each marked TEST-ONLY, not reviewed patches.
